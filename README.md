GAMEVERSE

GameVerse es una aplicación móvil que permite a los usuarios compartir, registrar y comentar su progreso en videojuegos. Funciona como una red social especializada donde la comunidad gamer puede interactuar, descubrir nuevos títulos y seguir la evolución de otros jugadores.

El objetivo es desarrollar una plataforma móvil que fomente la interacción entre jugadores mediante publicaciones, comentarios y seguimiento de avances en videojuegos, promoviendo una comunidad activa y participativa.
